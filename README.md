## 📌 Project Overview

A civic technology initiative designed to bridge agricultural knowledge gaps by providing farmers with voice-assisted support, multi-lingual problem triage, crop pathology advisories, and direct agricultural expert escalation.

---

## 🚀 Key Features

- **Voice-Assisted Problem Reporting:** Audio intake designed for accessibility across rural communities.
- **Agronomic Knowledgebase:** Rapid identification of crop diseases, pest controls, and seasonal advisories.
- **Agent Dashboard:** Real-time incident ticketing and regional outbreak mapping.

---

## 🛠️ Architecture & Tech Stack

| Layer | Technologies |
| :--- | :--- |
| **Voice & Backend** | Node.js, Express, WebRTC, WebSocket |
| **Advisory Engine** | Agricultural Disease Knowledgebase & Expert Routing |
| **Frontend** | Responsive Mobile-First Client Interface |

## 🚦 Getting Started

### 1. Clone the Repository
`ash
git clone https://github.com/chilkotiKartik/farmer-call-center.git
cd farmer-call-center
`

### 2. Install Dependencies
`ash
npm install
`

### 3. Run Development Server
`ash
npm run dev
`

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
